## Design System

- **Background:** `#ffffff`
- **Primary text:** `#000000`
- **Accent / header / footer / discount block:** `#000000`
- **Button:** Background `#000000`, text `#ffffff`, border `2px solid #000000`
- **Heading font:** Bebas Neue (Google Fonts), fallback: Arial Black, Impact, sans-serif
- **Body font:** Inter (Google Fonts), fallback: Arial, sans-serif
- **Max width:** 600px
- **Mobile breakpoint:** 620px
